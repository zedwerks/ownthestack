OpenMRS is distributed under the **OpenMRS Public License**, a variant of the Mozilla Public License 2.0 with an added healthcare-specific disclaimer addendum common to clinical open-source projects — the software is free to use, modify, and redistribute, with liability for clinical use explicitly disclaimed. Governance sits with the nonprofit **OpenMRS Inc.**, with technical direction set by community-elected leadership rather than a single commercial vendor's roadmap.

FHIR support is provided by the community-maintained **`openmrs-module-fhir2`** module, targeting **FHIR R4**, alongside an OpenMRS Core FHIR Implementation Guide describing which resources and search parameters are supported. This is real, actively maintained interoperability tooling — not a theoretical capability — though it is generic FHIR R4 support, not a Canada-specific profile.
