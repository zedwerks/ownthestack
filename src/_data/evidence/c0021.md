**EHRbase** is a self-hostable, open-source implementation of the openEHR Reference Model, Archetype Query Language, and openEHR REST API, built with contributions from Hannover Medical School's PLRI research group and the German health-IT firm vitagroup. Because it is open source and self-hostable, it can be deployed entirely on infrastructure located in Canada — directly relevant to the data-residency requirements that apply to provincial health data and that matter to every provincial ministry of health evaluating a foreign-hosted alternative.
